WHAT COMES NEXT

A measured roadmap.

Dates are intentionally not promised while critical security validation remains open.

COMPLETED · PROTOTYPE MILESTONE

Broker simulation and architectural source-fit research

Demonstrated basic cooperation, drain, and recovery state transitions; documented non-claims.

NEXT · BOUNDED REGRESSION

Fix connection-race constant and exercise S8

Correct the Win32 error mapping in the scratch prototype, then reproduce the intended connect-race path.

NEXT · ISOLATION EXPERIMENT

Test a real Windows service trust boundary

Validate service identity, narrow pipe rights, authenticated clients, protected resources and bypass resistance.

RESEARCH REQUIRED

Prove real filesystem admission and recovery properties

Address native pending-I/O, late writes, fencing, crash ordering, P1–P7 runtime and frozen contract changes before security claims.

FUTURE · CONDITIONAL

Product integration and wider ecosystem

Consider AegisFS integration into the separately developed File Manager only after technical and security gates are satisfied.
